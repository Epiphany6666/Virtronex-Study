# 邮件与告警

卡平台按场景发验证码信。文案枚举是 `EmailCopyScenario`，`{}` 换成 BU 的品牌名。信由 `virtronex-api` 经 Feign 调 `virtronex-email`。后台员工发码用另一份 `PlatformEmailCopyScenario`，模块不能依赖主站那份，同语义要两边一起改。

这一遍只收登录这一阶段已经碰到的发信。位数、验码、输错锁定见 `03-验证码与登录加固`。业务上谁在哪一步要这封信，见对应功能，不在这里重写。

| 场景 | 枚举 | 方式文案 |
|------|------|----------|
| 注册 | `MERCHANT_REGISTER` | Register for {} |
| 登录 | `MERCHANT_LOGIN` | Log in to {} |
| 重置登录密码 | `MERCHANT_RESET_LOGIN_PASSWORD` | Reset Login Password |
| 修改登录密码 | `MERCHANT_CHANGE_LOGIN_PASSWORD` | Change Login Password |
| 设置、修改、重置交易密码 | `MERCHANT_CREATE_PAY_PASSWORD`、`MERCHANT_UPDATE_PAY_PASSWORD`、`MERCHANT_RESET_PAY_PASSWORD` | Set / Change / Reset SecureKey |
| 验证器打开、关闭、重置 | `MERCHANT_GOOGLE_BIND`、`MERCHANT_GOOGLE_CLOSE`、`MERCHANT_GOOGLE_OPEN`、`MERCHANT_GOOGLE_RESET` | Turn on / Turn off / Reset Google Authentication。`OPEN` 和 `BIND` 的方式文案相同 |
| Google 登录的连接、断开、回访连密码 | `MERCHANT_GOOGLE_SIGNIN_BIND`、`MERCHANT_GOOGLE_SIGNIN_UNBIND`、`MERCHANT_GOOGLE_SIGNIN_LINK` | Connect / Disconnect / Link Google Sign-In |
| Apple 登录的连接、断开、回访连密码 | `MERCHANT_APPLE_SIGNIN_BIND`、`MERCHANT_APPLE_SIGNIN_UNBIND`、`MERCHANT_APPLE_SIGNIN_LINK` | Connect / Disconnect / Link Apple Sign-In |
| 后台强制解绑 Google、Apple | `FORCE_UNBIND_MERCHANT_GOOGLE`、`FORCE_UNBIND_MERCHANT_APPLE` | Force Unbind Merchant Google / Apple Sign-In。发到员工邮箱 |

谁在用：C 端用户收前八行。运营在 Authority 的绑定页点 Get code，收最后一行。见 `04-第三方登录`。

不包含，留到第二遍或各自的功能：

- 模板正文、维护邮件 `MAINTENANCE_NOTIFICATION`、系统告警 `virtronex-alert`
- 银行 `bank-email`。卡平台和银行是两套发信
- 登录提醒、钱包和卡的通知、KYC 通知、渠道 OTP
- 改邮箱、激活卡、钱包提币的验证码。枚举里有，这一遍不展开
- 验证码页怎么填。见 `03-验证码与登录加固`

分析分支：卡平台后端 `vtron_java_server` `dev`。2026-09-23 `git pull` 已是最新，`b28b4c9e2`。

前置数据：这一遍还没对着发信日志准备账号。注册、登录、Google 回访的 type 已经在 `03` 里对过枚举。强制解绑的 Get code 没点。
